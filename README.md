# DN 5.0 — DotNet FSE Deep Skilling Platform

**A world-class, self-contained learning management system for Cognizant's DN 5.0 DotNet Full Stack Engineering program.**

## 🚀 Quick Start

### Deploy to Vercel (Recommended - 5 minutes)
```bash
cd "DotNet FSE"
vercel --prod
```
Your site goes live at: `https://your-project.vercel.app`

### Deploy to Netlify (5 minutes)
```bash
cd "DotNet FSE"
netlify deploy --prod
```

### Deploy to GitHub Pages (Free)
```bash
git push origin main
# Enable Pages in GitHub Settings → Done
```

## ✨ Features

✅ **Single-file LMS** — Just `index.html`, no build needed  
✅ **14 Modules** — 23 mandatory tasks  
✅ **No Time Limits** — Learn anytime, at your pace  
✅ **Smart Dashboard** — What's Done, What's Next, What's Left  
✅ **All Files Accessible** — Download PDFs, docs directly from browser  
✅ **Progress Tracking** — Saves to localStorage (no server needed)  
✅ **Mobile-Optimized** — Works on phone, tablet, desktop  
✅ **Zero Dependencies** — Pure HTML/CSS/JavaScript

## 🔧 File Access Strategy
